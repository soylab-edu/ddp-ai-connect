# 웹디 — 헤더 연결 및 하단 레이아웃 검수

검수 대상: 원본 v12 본문에 v7 모션 헤더만 연결한 별도 page-review-v7.html. 하단 파일은 수정하지 않았습니다.

현재 판정: 하단의 기본 정렬과 섹션 구분은 유지되고 있으나, 헤더 연결 결함과 본문의 반복 카드·서체 강도 때문에 개선이 필요합니다. 전체 재설계보다 연결 오류 수정 → 정보량 정리 → 시각 스타일 정리 순서가 적절합니다.

## 현재 실행에서 확인한 데스크톱 단계
1. 헤더→본문 시작: 00-desktop-connection.png / 01-desktop-intro.png. 이중 스크롤 문제. 헤더/본문의 타이포와 그래픽 밀도 차이가 큼.
2. 프로그램: 02-desktop-program.png / 03-desktop-works.png 상단. 공개 시간 구분은 명확하지만 시간축 라벨이 왼쪽에 겹침.
3. 작품: 03-desktop-works.png / 04-desktop-lectures.png 상단. 3열 정렬은 정상. 내용이 같은 미공개 작품 12개로 영역이 길어짐.
4. 강의: 04-desktop-lectures.png. 2열 정렬은 정상. 강사·제목·시간·정원 미공개 상태인데 큰 카드 4장을 모두 노출.
5. 기업 참여: 05-desktop-partners.png. 4열 카드 정렬은 정상. 본문 설명과 보조 문구가 작고 가늘어 장문 내용의 읽기 부담이 있음.

데스크톱 근거: 현재 root 브라우저에서 생성한 1280×720 캡처를 웹디가 저장 파일로 직접 열어 확인. 전체 문서 높이 11,398px. 섹션 높이: 소개 1,353 / 프로그램 1,341 / 작품 1,697 / 강의 1,280 / 기업 1,733 / 공간 1,271 / 참여 안내 1,829px(root DOM 측정 전달).

## 우선순위
- P1 / 헤더 연결: iframe 내부 세로 스크롤바가 페이지 스크롤바와 함께 나타납니다. 스테이지 7:3 외에 독립 플레이어 조작바 높이가 포함되기 때문입니다. 임베드용 화면과 단독 플레이어를 구분해 부모 안에서는 내부 스크롤 없이 높이를 맞춰야 합니다. 조작바를 단순 숨길 경우 정지/재생 접근을 별도로 보장해야 합니다.
- P1 / 프로그램 시간축: 10–19시 라벨이 좌측 좁은 폭에 겹쳐 읽을 수 없습니다. .g-axis span 규칙이 첫 빈 grid 자식까지 absolute로 만들면서 #gAxis가 96px 첫 트랙으로 들어갑니다. #gAxis를 두 번째 트랙에 명시하거나 첫 직계 span만 일반 흐름으로 되돌리는 수정이 필요합니다.
- P1 / 헤더 CTA 연결(소스 확인): 최종헤더의 프로그램 보기·관람 안내는 span이며 본문 #program/#guide로 연결되지 않습니다. 실제 링크/버튼과 부모 탐색 연결이 필요합니다. 클릭 동작은 root 추가 확인 대상입니다.
- P2 / 정보량: 작품 12개가 모두 추후 공개, 강의 4개도 정보가 비어 있습니다. 확정 내용 전에는 카테고리별 안내와 공개예정 요약을 먼저 보여주고, 실제 콘텐츠가 들어왔을 때 전체 그리드를 펼치는 편이 좋습니다.
- P2 / 헤더와 본문 시각 연결: 본문 기본 정렬을 유지하되 본문 폰트·회색 명도를 정리하고, 둥근 카드/희미한 장식보다 굵은 타이포·단순 선·분명한 색면으로 연결하는 것이 좋습니다. 원본 헤더만큼 본문 전체를 강하게 만들 필요는 없습니다.

## 검수 한계
웹디 서브 브라우저는 접근 불가로 root의 현재 실행 캡처와 DOM 측정, 소스를 함께 검토했습니다. 화면과 소스에 근거한 검수이며 실제 링크 테스트·키보드 탐색·스크린리더 전수 검사를 의미하지 않습니다. 모바일 및 공간/참여 안내 캡처 검토가 추가될 예정입니다.
