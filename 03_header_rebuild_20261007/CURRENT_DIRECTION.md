## 두 제작안의 차이

**A: 라인 드로잉 + 키네틱 타이포**

사용자 지정 참고: https://dribbble.com/shots/27503138-Coffee-Brand-Illustrations-Motion-Graphics-Design

삼삼오오 네트워킹하는 사람, 태블릿으로 AI를 함께 경험하는 사람, 상담하는 사람을 2D 라인 드로잉으로 표현한다. 원작의 자연스러운 선과 인체 비례, 먹면과 여백을 참고한다. 컬러는 소이랩 팔레트를 쓴다. 큰 타이포와 선화 장면이 리듬 있게 교차한다. 기존의 각진 면, 그라디언트 인체, 입체 인형, 분리된 손 장면은 폐기한다.

**B: 추상 조형 + 키네틱 타이포**

인물 없이, 분절된 판의 정렬·엇갈림·연결과 입체 타이포를 사용한다. 큰 스케일과 화면 전체의 색면 전환으로 A와 다른 시각적 해법을 만든다. 여러 컷이 같은 물체의 회전처럼 보이지 않도록 구도와 밀도를 바꾼다.

## 검수와 작업 순서

1. 각 안의 실제 주요 프레임을 부모와 검수자가 확인한다.
2. 실제 영상에서 움직임, 컷의 속도와 차이, 타이포 가독성, 인체 오류를 확인한다.
3. 한 번 재생 후 최종 화면 유지, 다시 보기·일시정지, 작은 화면, 동작 줄이기를 확인한다.
4. 헤더 완성 후 하단을 다시 다룬다. 현재 v12 본문은 확정안이 아니다.
5. 본문은 원래 03번의 정보와 구성, 01번의 레이아웃과 디자인을 대조해 수정한다. 레퍼런스를 무시하고 새로운 카드·그림 체계로 임의 재구성하지 않는다.

원본 01·03 HTML과 사용자 영상은 보존한다. 이전 시안은 최종 결과로 제시하지 않는다.

## 최신 지시 — 독립 C안 제작 재개

이후 사용자가 구체적인 C안 연출과 실제 로고 오버랩을 지시했다. A·B는 동결하며 **최종 헤더 시안은 A·B·C 총 3개**다. C 제작을 진행하고, 만들어지는 스틸과 영상은 준비되는 즉시 보여준다.

- 블랙 배경. 왼쪽은 작은 파스텔 닷으로 구성한 구, 오른쪽은 약 45도 원근으로 기울여 미세하게 움직이는 레드 입체 SOYLAB.
- 닷이 하나씩 포물선을 그려 로고로 이동한다. 접촉한 지점에서 닷의 색이 물감처럼 표면을 따라 번진다.
- 닷의 이동이 가속되고, SOYLAB은 검은 유광 입체가 되면서 커져 중앙으로 이동한다. 반사광과 윤곽광으로 검정 배경에서 형태를 읽히게 한다.
- 카메라 방향의 앞뒤 바운스 후 폭발. 이 순간 실제 파일 `D:/DDP/03_assets/soylab-logo.png`를 오버랩한다.
- 폭발을 양방향 텍스트 웨이브로 연결한 뒤 행사 메시지·일시·장소로 정착한다.
- 새 폴더 `concept-c-convergence`. 코드로 제작하며 실제 로고 파일은 그대로 사용한다. A·B 또는 원본 01·03을 덮어쓰지 않는다.
