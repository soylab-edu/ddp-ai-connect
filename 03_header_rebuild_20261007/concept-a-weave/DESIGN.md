# Design
개성 있는 인물들이 리본을 당기고 건네고 함께 쓰는 모습으로 연결을 표현하는 현대 일러스트 모션 포스터.
Purple #7A00EE / lime #DFFF64 / coral #FB735C / paper #F4F0E7 / ink #171522. 고정 행사정보는 paper/ink 유지. Pretendard ExtraBold + Regular 로컬 WOFF2.
평면 도형을 깊이 있게 겹치며 실루엣/손/표정/옷 주름/리본의 앞뒤면을 직접 제작. 1컷1주인공. 인물·밴드·도구의 크기/시점/구도를 바꿔 장면마다 새로운 시각 정보를 제공. 정보는 고정 바, 창작은 전면 무대. 광고 패널/카드/연결선 다이어그램 없음.
