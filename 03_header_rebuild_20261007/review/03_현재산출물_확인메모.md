# 현재 산출물 확인 메모 — 사용자 검토 대기

사용자가 “임팩트가 없어. 우선 작업한 거 다 확인하고 다시 얘기하자”라고 요청했다. 따라서 추가 디자인 수정 제안과 검수 범위 확장을 멈춘다. 아래는 직접 확인한 범위와 미확인 부분의 기록이며 품질 합격이나 최종안 선정이 아니다.

## 함께 대조한 기준

- 원03 HTML의 행사 구성·정보·소이랩 브랜드색. 최신 지정 팔레트는 퍼플 `#7A00EE`, 네온그린 `#CCFF00`, 블랙 `#111111`, 레드 `#DF0221`, 가독성 보조 화이트다.
- 원01 업로드 영상 `D:/DDP/헤더모션01파일샘플.mp4`의 실제 추출 프레임. 작은 점에서 큰 숫자로의 스케일 변화, 단일 실루엣에서 조밀한 전면 패턴으로의 변화, 대형 단어의 짧은 색면 컷, 최종 정보 포스터의 정착을 새 렌더와 나란히 비교했다.
- A용 새 Dribbble 레퍼런스의 실제 캡처 `review/dribbble-reference-observed.jpg`. 자연스러운 선화 표현을 관찰했다. 검수 담당은 캡처를 직접 봤고 해당 사이트의 영상 전체를 직접 재생한 것은 아니다.
- 사용자 미감 기준: 심플·과감·강렬·세련됨·아트. 기술적 정상 동작을 이 미감의 달성으로 대체하지 않는다.

## A — 인물 선화와 키네틱

마지막으로 직접 본 화면은 `concept-a-weave/snapshots/peeps-v1/contact-sheet.jpg`의 6컷이다. 검수 사본은 `review/evidence/a-peeps-v1-six-check.jpg`다.

공식 OpenPeeps 완성 SVG를 사용한 3인 대화, 두 사람과 태블릿, 상담 테이블, 큰 한국어 타이포, 최종 인물/문장 구성을 보았다. 앞서 반려한 직접 제작 도형 인체와는 자산·선 표현이 바뀌었다. 현재 3인 장면은 양쪽 인물이 그룹 안쪽으로 제스처를 보내는 구도이며 기존 일렬 정면 아바타보다 관계를 표현하려는 배치가 있다. 이것이 사용자가 원하는 임팩트를 충족했다는 판정은 하지 않는다.

확인 당시 태블릿 장면의 작은 테이블/기기가 인물보다 위에 떠 보였고, 제작자가 위치를 수정 중이라고 보고했다. 수정 후 화면은 아직 직접 확인하지 않았다. A 완성 MP4, 모바일, 웹 재생/버튼은 이 담당자의 검수 범위에서 아직 확인하지 않았다.

과거 반3D 인물 초안과 처음 직접 그린 선화 초안은 반려 기록으로 남아 있으며 현재 시안의 승인 근거가 아니다. 이후에는 승인된 완성 SVG 포즈를 보존하는 방향으로 진행됐고, 검수 담당이 얼굴 표정 삭제나 인체 재작성 같은 새 방향을 요구하지는 않았다.

## B — 인물 없는 분절 슬래브와 추상 키네틱

마지막으로 직접 본 화면은 `concept-b-playground/snapshots/final/contact-sheet.jpg`, `snapshots/final-mobile/contact-sheet.jpg`다. 사본은 `review/evidence/b-final-desktop-check.jpg`, `b-final-mobile-check.jpg`다.

원01 실제 프레임과 나란히 비교한 결과, B 안에서 단일 판 → 다수 분절 → 밀집 필드 → 성긴 두 집합 → 입체 사람/AI → 순색 장르 단어 → 최종 포스터라는 서로 다른 장면이 존재함을 확인했다. 브랜드 네 가지 색과 글자 대비가 보인다. 모바일의 첫 판 외곽, ‘사람’ 두 글자, 검정 필드 안 네온 엣지 조정이 반영됐다. 최종 문장/날짜/장소/CTA가 서로 겹치지 않는 것도 스틸에서 확인했다. 이는 요소와 수정 반영 여부의 확인이며 미감 합격을 뜻하지 않는다.

직접 표본 검수한 `preview.mp4`는 ffprobe 기준 1440×900, 30fps, 15초다. 실제 MP4를 2fps로 추출한 30프레임의 사본은 `review/evidence/b-preview-2fps-check.jpg`다. 해당 표본에 검정 빈 프레임이나 콘텐츠 누락은 없었고 마지막 포스터가 안정돼 있다. 실시간 재생으로 모든 순간을 직접 관찰한 것은 아니다.

웹 파일 `header-b.html`의 자동 재생·일시정지·15초 최종 유지는 메인이 허용된 브라우저에서 확인했다고 전달했다. 제작자는 별도 동작 검사에서 pause/resume, replay, 최종 유지, reduced-motion, 가시성, CTA 분기가 통과했다고 보고했다. 검수 담당이 이 웹 동작을 직접 브라우저에서 수행한 것은 아니다. 버튼 포커스 시 내부 스크롤 문제는 수정 후 메인이 재확인 중이었다.

## 아직 확인하지 않은 최신 변경과 본문

- 사용자가 추가한 원03 `.kin` 두 줄을 헤더 안에 넣는 최신 변경은 위 A/B 스틸과 MP4 검수 이후 요청됐다. 그 변경이 반영된 최종 화면·모바일·재출력 영상은 아직 직접 검수하지 않았다. 원문은 첫 줄 `사람 AI 사람 間 GAME ART STORY 間`, 둘째 줄 `CONNECT 12.09–10 DDP NEXT K-CORE`다.
- 원03 본문과 새 v12의 연결에 대한 충돌 체크리스트는 `review/01_v12_연결검수_체크리스트.md`에 있다. 본문 시안은 아직 확정하지 않았으며, 헤더 우선 진행 중 실제 본문 검수를 보류했다. 현재 본문이 원03 정보와 원01 디자인을 모두 충족한다고 판정하지 않는다.
- 사용자 요청에 따라 현재 산출물을 먼저 보여주는 단계다. 추가 수정과 새 방향 제안은 사용자 검토 전까지 멈춘다.

세부 검수 경과와 과거 반려 근거는 `review/02_키프레임_검수기록.md`에 보존했다.
