# C 통합 헤더 · 전체 흐름 검수

> 최종 상태: 실제 HQ MP4의 전체/연결 샘플과 17.8초 수정 프레임 검수 완료. 모바일 정지 샘플도 확인했으며 추가 시각 수정 요청은 없다. 아래 초기 대기/수정 요청은 진행 기록이고 마지막 절이 최종 판정 범위다.

2026-10-07. 범위: 새 `concept-c-integrated`의 전체 이야기와 장면 연결을 검수한다. 기존 A/C/B, HUMAN 컴포넌트, 본문, 새 프로덕션 코드와 shot-plan은 수정하지 않는다. 실제 샘플은 제작자 또는 ROOT에게 받으며 별도 렌더를 동시에 돌리지 않는다.

## 현재 사용자 의도

레퍼런스 하나를 단독 영상으로 만드는 것이 아니라 기존 C의 닷→SOYLAB→폭발/실제 로고→HUMAN/AI 장면→8줄 웨이브→사람 중심 최종 포스터 흐름에 활용한다. 기존 9초 HUMAN은 보존된 컴포넌트다. 컴포넌트 자체의 검수 완료를 통합 헤더의 완성으로 대신하지 않는다.

## 핵심 검수 기준

1. **전체 이야기 보존**: 시작부터 원래 C의 닷/표면 접촉/가속/SOYLAB/폭발/실제 로고가 주역이어야 한다. HUMAN이 전체를 대체하거나 독립된 다른 영상처럼 끼어들지 않아야 한다.
2. **접속과 동일성**: 10.2–10.9초에 로고/폭발의 한 lime 점이 HUMAN의 동일한 구슬로 연결된다. 두 구슬, 순간이동, 검은 빈 프레임, 불필요한 새 카메라 컷이나 서로 다른 셸의 중복 정보가 없어야 한다. 작은 AI는 경유지로 읽히고, 구슬은 HUMAN으로 귀환한다.
3. **후반 흐름과 정보**: 한 번의 짧은 귀환 강조 후 8줄 반대 방향/단어별 상하 웨이브가 나오고 최종 사람 포스터로 정착한다. 상단 정보는 한 셸에서 유지되며 데스크톱/모바일에 겹침과 잘림이 없어야 한다. 기존에 고친 최종 하단 웨이브의 전체 폭과 웹의 지속 움직임도 보존한다.

## 실제 검수 상태

통합본 실제 샘플을 기다리는 상태다. 아직 통합본의 시각적 완성이나 동작 통과를 주장하지 않는다. 제작자에게 전체 contact sheet와 10.2–10.9 / 약12.7 / 14–14.9 / 17.5–20초 연결 샘플을 준비되는 대로 직접 알려 달라고 요청했다.

## 첫 통합 샘플: 전체 흐름 및 로고 연결

제작자의 `snapshots/integrated-first/contact-sheet-1.jpg`와 `contact-sheet-2.jpg`의 전체 12컷을 직접 확인했다. 10.65/17.8/19.8초 원본 1600×640도 보았다. 이어서 `snapshots/bridge/contact-sheet.jpg`의 10.2–10.9초 0.1초 간격 8컷 및 10.3초 원본을 직접 보았다. 중요 시트/프레임을 `review/evidence/integrated-*` 고유 이름으로 보존했다.

**확인한 흐름:** 원래 C의 닷 구체→빨간 입체 SOYLAB→검정 광택 SOYLAB→폭발/실제 SOY./LAB 로고가 전반부에 유지된다. HUMAN은 그 뒤의 중간 장면이고 이어서 8줄 웨이브와 최종 사람 포스터가 나온다. 레퍼런스 장면만 단독으로 보여 주던 문제는 이 통합 시트의 장면 구성에서 해소되었다.

**로고에서 HUMAN 연결:** 10.3초 실제 PNG의 O 안에 작은 네온그린 구슬이 보인다. 이후 위쪽 호를 따라 좌측 H의 시작점으로 이동하고 10.8/10.9초에는 HUMAN 시작점의 같은 색 구슬로 이어진다. 이 0.1초 간격 샘플에 구슬 복제나 검은 빈 화면은 보이지 않는다. 로고/HUMAN 교차는 짧은 겹침으로 연결되고 구슬이 장면 사이를 잇는다. 3D/bridge에 추가 수정 요청은 없다.

**수정 요청 1건 — 포스터 진입:** 17.8초 원본에서 위쪽 6개 웨이브 행이 포스터 제목, 날짜, CTA를 진하게 가로질러 이중 문구로 보인다. ROOT(웨이브 소유자)에게 포스터가 읽히기 시작할 때 위 6행을 먼저 빠르게 지우고 하단 2행을 유지하도록 전환 위상을 정리해 달라고 요청했다. 20초 전체 길이와 8줄 웨이브 구간은 유지할 수 있는 문제다. `integrated-first-poster-overlap-17p8.png`가 실제 증거다.

19.8초 최종 화면은 큰 중복 웨이브가 사라져 깨끗하고, 하단 2행은 오른쪽 끝까지 채워져 있다. 아직 웹 20초 이후의 지속 움직임은 이 정지 화면으로 검증하지 않았다. font404/h1 span bbox 경고는 셸 제작자가 수정 중이라는 보고를 받아 중복 요청하지 않았다. 모바일과 최종 인코딩 샘플은 아직 보지 않았다.

## 17.8초 전환 의견의 범위 정정

ROOT가 17.5–18.3초를 의도한 웨이브/포스터 교차 구간이라고 확인했다. 내가 직접 본 근거는 17.8초 한 시점의 시각적 혼잡이며, **지속적인 읽기 결함은 확인하지 못했다**. 19.8초는 깨끗하다. 따라서 앞선 요청은 HQ 출력을 막는 필수 버그가 아니라 전환을 다듬는 의견으로 낮춰 전달했다. 최소 제안은 전체 교차 구간과 하단 2행을 유지하고, 상단 6행의 불투명도만 17.5–17.72초에 먼저 지우거나 빠른 감쇠를 적용하는 것이다. 이 의견만으로 소스 고정을 풀고 추가 검사를 늘릴 필요가 있다고 주장하지 않는다.

## 모바일 실제 7컷

`snapshots` 제작자는 통합 모바일 390×720 시트를 제공했다. 리뷰어는 `concept-c-integrated/mobile/snapshots/integrated-first/contact-sheet.jpg`의 0/10.3/10.9/12.6/14.2/15.8/19.5초 7컷을 직접 보았고, `review/evidence/integrated-mobile-seven.jpg`로 보존했다.

- 실제 로고→HUMAN→작은 AI 경유→귀환 강조→8줄 웨이브→포스터가 모바일에서도 같은 순서로 이어진다.
- HUMAN 다섯 글자와 작은 AI가 화면 안에 있고, 주요 한글·날짜·장소·최종 CTA가 읽힌다. 장면과 정보의 겹침이나 조형 잘림은 보이지 않는다.
- 15.8초의 반복 단어가 좌우 가장자리에서 잘리는 것은 가로 웨이브의 정상적인 크롭이며, 중요 행사 정보 잘림과 구분한다.
- 19.5초 하단 2행은 화면 오른쪽 끝까지 채워져 있다. 첫 0초의 메타 정보 부재는 제작자가 설명한 기존 C의 첫 1.3초 순차 진입이며 새 오류로 보지 않았다.
- 모바일 추가 수정 요청은 없다. 제작자 보고의 lint/runtime/layout 0 및 contrast 23/23, 로컬 fullfont 정상은 리뷰어가 직접 테스트한 수치가 아니라 제작자의 검증 보고다.

남은 확인 범위는 최종 인코딩 전체 샘플과 ROOT의 실제 웹 지속 동작 확인이다. 현재 정지 샘플에 근거한 시각 검수에서 출력을 막을 결함은 없다.

## 최종 HQ 인코딩 검수 완료

대상은 `concept-c-integrated/preview-integrated-hq.mp4`다. 제작자 확인 규격은 3200×1280, 30fps, 600프레임, 20초다. 이 규격 수치는 제작자의 최종 렌더/메타데이터 보고이며 리뷰어가 중복 인코딩이나 ffprobe를 다시 실행한 것은 아니다.

리뷰어가 직접 본 것은 실제 MP4에서 추출한 다음 자료다.

- `review-encoded/whole-2fps-1.jpg`, `whole-2fps-2.jpg`: 전체 20초를 2fps로 추출한 40컷.
- `review-encoded/bridge-4fps.jpg`: 10.2–14.9초 연결/귀환 구간 약 4fps 20컷.
- `review-encoded/poster-transition-17.8s-hq.png`: 17.8초의 3200×1280 원본 프레임.
- 위 자료는 `review/evidence/integrated-final-encoded-*`로도 보존했다.

**결과**

1. 닷 구체에서 한 점씩 비행→여러 점으로 가속/표면 색 확산→검정 SOYLAB→폭발과 실제 로고→한 lime 구슬로 HUMAN 진입→작은 AI 경유/HUMAN 귀환→8줄 웨이브→최종 사람 포스터라는 전체 순서가 실제 인코딩 샘플에 유지된다. HUMAN 레퍼런스 장면이 전체 헤더를 대체하지 않는다.
2. 연결 구간 샘플에서 동일한 lime 구슬이 로고에서 H로 이어지고, H 획/아래 경로/AI/위 경로를 거쳐 귀환한다. 구슬 복제, 큰 순간이동, 빈 장면은 보이지 않는다. 전체 실시간 영상을 리뷰어가 직접 연속 재생한 것으로 주장하지 않으며, 판단 범위는 실제 인코딩 샘플이다.
3. **17.8초 상단 6행이 완전히 사라져 앞선 포스터 중복 의견이 해결됐다.** 포스터 자체는 의도된 진입 불투명도 상태이며 하단 2행만 남는다. 이후 18–19.5초 샘플에서는 포스터가 선명하게 정착하고 하단 두 행의 단어 위치가 계속 바뀐다. 두 행은 오른쪽 끝까지 채워져 있다.
4. 앞서 확인한 모바일 390×720의 순서·조형 경계·한글 정보·CTA 확인 결과와 함께, 현재 리뷰 범위에서 추가 시각 수정 요청은 없다.

ROOT는 실제 웹에서 최종 포스터, 일시정지, 다시 재생을 확인했다고 보고했다. 이 실제 웹 확인은 ROOT의 검증 범위로 구분한다. 리뷰어는 별도 브라우저 검사나 중복 렌더를 실행하지 않았다. 최종 취향 및 공개/납품 판단은 사용자와 ROOT가 담당한다.
