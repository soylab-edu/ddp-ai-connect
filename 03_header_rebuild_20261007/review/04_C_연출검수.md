> 최신 사용자 변경: 데스크톱 A/B/C를 1600×640으로 넓힌다. C 초반에는 왼쪽 슬로건/오른쪽 일정이 읽히는 텍스트 모션을 넣는다. 기존 큰 두 줄 웨이브는 32–38px 정도의 작은 8줄로 바꾸고 행별 반대 방향과 순차 파동을 유지한다. 아래 두 줄 모듈 관찰은 이전 버전 기록이며 새 8줄/새 비율의 통합 출력은 아직 확인 전이다.

A/B는 사용자가 확인할 완성 검토용으로 동결했다. C는 사용자가 새로 지정한 연출을 확인한다. 검수 범위는 요청한 순서와 실제 화면 결함이며 임의의 새 디자인 방향을 제안하지 않는다. 초기 스틸부터 확인해 부모에게 바로 전달하고, 전체 렌더가 끝날 때까지 결과 공유를 늦추지 않는다.

## 사용자 지정 순서

1. 검정 배경의 왼쪽에 파스텔 작은 점들로 된 작은 구체가 보인다.
2. 점이 하나씩 곡선 경로를 따라 오른쪽으로 이동한다. 오른쪽에는 약 45도 기울어 살짝 움직이는 빨간 3D SOYLAB이 있다.
3. 각 점이 닿는 위치에서 물감색이 로고 표면으로 퍼진다. 단순히 주변에 색 입자가 떠 있는지와 구별해 본다.
4. 점 이동이 빨라진다.
5. SOYLAB이 검정 유광 3D로 바뀌면서 커지고 화면 중앙으로 이동한다. 검정 배경에서도 흰 반사광과 색 테두리로 형태가 읽혀야 한다.
6. 앞뒤로 바운스한 뒤 터진다.
7. 터지는 순간 실제 `D:/DDP/03_assets/soylab-logo.png`가 겹친다.
8. 양방향 텍스트 웨이브가 이어진다.
9. 행사 정보 포스터로 끝난다.
