## 최신 사용자 교정 이후의 검수 기준

사용자가 직접 명시한 최우선 미감은 **심플·과감·강렬·세련됨·아트**다. 한 화면에 주도 형태 하나, 큰 스케일, 강한 색면, 엄격한 여백, 짧고 선명한 전환으로 판단한다. 밋밋한 대시보드나 제품 설명 그림이면 디테일 수정 단계로 넘기지 않고 방향 자체를 반려한다. A의 리본 교차·직조와 B의 분절 직육면·키네틱 오브젝트는 서로 구별돼야 한다.

사용자 요청: 벡터 인물 사용 중단, 제공한 영상의 그래픽 방향으로 재정렬. 메인 디렉션: 인물 일러스트 서사를 접고 A는 리본·간격·프레임의 큰 변형/규칙 필드/교차/직조, B는 입체 추상 필드/형태 연결을 만든다. 사람·얼굴·손과 게임패드·책·액자의 나열은 새 방향에서 제외한다.

새 6컷의 첫 판정은 미감과 방향이다. 기술 체크 통과로 이를 대신하지 않는다.

1. 화면 전체를 점유하는 조형과 큰 스케일 변화가 있는가. 작은 중앙 오브젝트나 여백 속 단어 교체만 이어지면 반려한다.
2. 규칙/밀도/개수/형태가 서로 다른 장면이 있는가. 같은 형태의 색·회전·위치만 바뀌는 반복이면 반려한다.
3. 면을 덮는 전환, 교차나 직조, 밀도 상승과 해소가 실제로 보이는가. 단순 페이드 슬라이드쇼이면 반려한다.
4. 제공된 01 영상의 다양성·밀도·스케일·템포를 새 그래픽 언어로 구현했는가. 기존 형태와 색 순서를 복제하거나 제작자의 임의 일러스트 서사로 바꾸면 반려한다.
5. 짧은 장르 타이포는 조형 리듬을 보조하고, 마지막에는 정돈된 행사 포스터로 안정되는가. 계속 움직이는 장식 때문에 정보가 흐트러지면 수정한다.
6. 과도한 형광색/장난감 재질/스티커의 나열을 피하면서도 그래픽의 양과 변화가 충분한가. 애플스러움을 빈 화면의 동의어로 해석하지 않는다.

실제 이미지로 먼저 방향을 판단하고, 그다음 영상 전환·모바일·재생/정지/접근성·본문 연결을 따로 확인한다. 아직 새 추상 방향의 산출물은 검수하지 않았다.

## 최신 Dribbble 레퍼런스 반영 — A/B 역할 분리

부모가 실제 재생 후 저장한 `review/dribbble-reference-observed.jpg`를 검수 담당이 직접 열어 보았다. 검수 담당은 해당 정지 캡처만 보았으며 레퍼런스의 전체 동작은 직접 재생 검증하지 않았다.

- A: 크림과 먹색 위주의 2D 선화. 유기적인 외곽선, 검정 머리/바지의 큰 면, 자연스러운 몸과 손 비례, 후드·신발·옷 접힘의 구체 디테일, 얼굴 이목구비 생략이 관찰된다. 새 콘텐츠는 네트워킹·태블릿 AI·상담과 키네틱으로 만든다. 과거 반3D 인물의 도형 몸통·원형 머리·큰 열린 손은 재사용하지 않는다. 먼저 한 컷의 그림 언어가 실제 레퍼런스와 맞는지 확인한다.
- B: 인물 없이 분절 직육면/슬래브/입체 추상 필드를 사용한다. 화면 점유율·스케일·밀도·강한 색면·짧고 선명한 전환으로 01 영상의 쇼릴 성격을 확인한다.
- 공통 미감: 심플·과감·강렬·세련됨·아트. 기술 완성도와 미감 적합성을 따로 판단한다.
- 본문 시안 확정/검수는 현재 보류한다. 헤더가 방향을 얻은 뒤 원03 구성/정보와 원01 디자인을 실제로 다시 대조한다.

2. **장면 변화 검증:** 3.2/9.3/13.5초가 모두 수직 핀 필드로 읽힌다. 전체 움직임에서 같은 슬랫 물체의 회전만 반복하는지, 단일 덩어리에서 분절/밀집/열림으로 실루엣과 밀도가 실제 변하는지 확인해야 한다. 정지 6컷만으로 리듬 통과를 판정하지 않는다.
3. **전면 그래픽의 강도:** 상하 정보 레일이 대부분의 그래픽을 중앙 직사각형 창에서 끊는다. 적어도 한 강한 컷은 조형이 화면 전체 또는 정보 뒤까지 점유해 화면을 덮는 스케일을 가져야 한다. 고정 정보의 존재 자체보다 모든 컷의 동일한 안전 영역이 문제다.

모바일, 완성 영상, 전환의 실제 리듬은 아직 검증하지 않았다. 메인에게 같은 6컷을 직접 보고 미감 방향을 판단하도록 전달했다.

## B 최종 스틸 및 실제 MP4 표본 검수

`snapshots/final/contact-sheet.jpg`, `snapshots/final-mobile/contact-sheet.jpg`를 직접 확인하고 사본 `review/evidence/b-final-desktop-check.jpg`, `b-final-mobile-check.jpg`에 보존했다. 모바일 첫 판의 외곽, 7.15초 '사람' 두 글자, 3.2초 검정 분절 안의 네온 엣지가 실제 보인다. 요청한 세 모바일 조정이 반영됐다. 이 범위에서 추가 시각 수정은 요청하지 않았다.

실제 `concept-b-playground/preview.mp4`는 ffprobe 기준 1440×900, 30fps, 15초다. 영상은 scene.js 수정 이후 생성됐다. MP4에서 2fps로 추출한 30개 프레임을 `review/evidence/b-preview-2fps-check.jpg`로 직접 확인했다. 판 분절 → 밀집 필드 → 성긴 두 집합 → 입체 사람/AI → 순색 장르 단어 → 최종 포스터의 순서와 밀도 변화가 보이며, 표본 안에 검정 빈 프레임/콘텐츠 누락은 없다. 최종 구간에서는 포스터와 정보가 안정돼 있다.

이는 실제 MP4의 프레임 표본 검수다. 실시간 재생을 직접 보고 모션의 모든 순간을 검증했다는 뜻은 아니다. 웹의 자동 1회 재생, 최종 고정, 정지/재생 버튼, reduced-motion 동작은 별도 확인이 남아 있다. 최종 미감 선택은 메인이 실제 화면과 사용자의 기준으로 결정한다.
