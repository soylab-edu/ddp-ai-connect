# A 걷기와 새 타이포 검수

사용자가 A의 인물이 걷고 움직이도록 요청했다. 몇 걸음 다가와 멈추고 손짓하면 상대가 고개로 반응하는 동작을 확인한다. 인물 전체의 수평 이동만으로 걷기를 구현했다고 판단하지 않는다. 새 인물 스타일이나 표정 삭제 같은 방향은 제안하지 않는다.

사용자가 거대한 Pretendard ExtraBold 한국어를 거절한 뒤 새 타이포를 지정했다. `DDP`, `12월`, `사람과 AI`, `AI와 사람`, `사람과 사람`, `Soylab.ai`를 중앙 한 줄에 여백을 두고 입장/퇴장/드롭/줌으로 보여준다. 메인 기준은 IBM Plex Sans KR 500–600과 Outfit 600, 1440 기준 약 60–90px이며 아트/타이포를 교대한다. ‘함께 만드는 다음 장면’은 삭제하고 레드·네온·블랙을 분배한다. 최종 데스크톱 비율은 최신 지시에 따라 1600×640이다. 이 타이포 크기 제한은 C의 요청된 3D 확대/폭발에는 적용하지 않는다.

## 관절 테스트 v1

`concept-a-weave/motion-test/snapshots/rig-v1/contact-sheet.jpg`의 8컷과 0.6/3.2초 원본 PNG를 직접 확인했다. 사본은 `review/evidence/a-walking-rig-v1-eight.jpg`다.

서로 다른 시점에서 발이 번갈아 들리고 무릎이 굽어, 인물 전체를 평행 이동만 한 상태와 구별된다. 본 프레임에서 팔다리가 추가되거나 다리와 발이 떨어진 상태는 보이지 않았다. 자연스러운 전체 운동을 검증한 것은 아니며 실제 걷기 영상은 아직 확인 전이다.

제작자가 바닥선/밑창 높이와 마지막 무릎 굽힘을 직접 발견해 수정 중이라고 보고했다. 검수에서 추가로 확인한 관계 결함은 오른쪽 듣는 인물이 화자의 반대인 화면 오른쪽을 바라보는 점이다. 3.2초 반응에서도 서로 마주보지 않아, 완성 포즈를 좌우반전해 화자 쪽을 보도록 요청했다. 의상/얼굴/그림 언어의 변경 요구는 하지 않았다.

수정 후 접지, 실제 4초 동작, 새 타이포 및 1600×640 전체 배치는 아직 확인 전이다.

## 수정 후 실제 MP4와 스틸 확인

`motion-test/motion-test.mp4`는 1600×640, 30fps, 4초이고, `type-test/type-test.mp4`는 1600×640, 30fps, 4.5초다. 각각의 실제 연락시트와 MP4 표본을 직접 확인했다. 증거 사본은 아래와 같다.

- `review/evidence/a-walk-corrected-eight.jpg`: 제작자의 수정 후 8컷.
- `review/evidence/a-walk-4s-6fps.jpg`: 실제 걷기 MP4에서 6fps로 추출한 24프레임.
- `review/evidence/a-type-six-cues.jpg`: 지정된 여섯 문구의 스틸.
- `review/evidence/a-type-4p5s-4fps.jpg`: 실제 타입 MP4에서 4fps로 추출한 18프레임.

걷기 표본에는 발 교대 → 이동 정지 → 손 방향 변화 → 상대 고개 변화의 순서가 있다. 오른쪽 인물이 이제 화자 쪽을 바라보며 정지 후 다리도 펴진다. 표본에 다리/발 단절이나 추가 팔다리는 보이지 않는다. 실제 시간의 전체 운동을 직접 재생 관찰한 것은 아니므로 자연스러움에 대한 최종 합격으로 표현하지 않는다.

타입 스틸에서 여섯 문구가 모두 중앙 한 줄로 보이고 충분한 여백이 있다. 기존 화면을 꽉 채운 굵은 한국어는 없어졌으며 블랙/레드/네온/퍼플이 분배된다. 제작자는 IBM Plex Sans KR 600/Outfit 600, 72px로 제작했다고 보고했다. 4fps 표본은 빠른 입출장 동작의 모든 순간을 포함하지 않으므로 각 전환의 미세한 운동을 완전 검증한 것으로 표현하지 않는다.

현재 모듈에는 새 방향 수정 요청을 하지 않았다. 본안 통합 후 1600×640에서 인물/타입/고정 정보/kin 줄의 겹침은 아직 확인 전이다.

## animated-v2 통합 11컷

`snapshots/animated-v2/contact-sheet-1.jpg`, `contact-sheet-2.jpg`의 11컷과 7.6/13.7초 원본을 직접 확인했다. 사본은 `review/evidence/a-integrated-v2-01.jpg`, `a-integrated-v2-02.jpg`다.

1600×640에서 메타 정보, 중앙 한 줄 타이포, 주요 인물이 잘리거나 서로 겹치지 않는다. 태블릿이 원형 거치대 위에 놓여 있어 과거 공중에 떠 있던 장면과 구별된다. 현재 제작본에는 wave가 없다고 제작자가 보고했고 실제 스틸에도 보이지 않는다. 이 상태를 메인에게 전달했으며 검수 담당이 별도 새 연출을 추가 지시하지 않았다.

실제 소품 접촉 문제 한 개를 전달했다. 13.7초 상담 장면에서 오른쪽 인물의 뻗은 신발 끝이 테이블 오른쪽 모서리와 맞물려 발을 테이블에 올린 듯 보인다. 인물 포즈는 보존하고 테이블 오른쪽 폭만 조금 줄여 간격을 확보하도록 요청했다. 이 수정 후 화면과 통합 모바일/완성 영상은 아직 확인 전이다.

## 소품 간격과 최종 모바일 수정 확인

`preview-animated.mp4`는 ffprobe 기준 1600×640, 30fps, 17초다. 실제 MP4에서 추출한 `snapshots/animated-final/consultation-video.png`를 직접 확인했고 데스크톱 상담의 테이블/신발 간격이 확보됐다.

`mobile-animated/snapshots/final/contact-sheet.jpg`의 4컷과 7.6초 원본을 직접 확인했다. 날짜/장소가 각 줄로 나뉘어 있고 메타/CTA가 읽힌다. 최초 모바일 7.6초에는 오른 신발이 태블릿 우상단에 겹쳐 있었다. 제작자가 기기와 거치대를 왼쪽으로 15px 이동한 후, `review/evidence/a-mobile-tablet-fixed-check.png`라는 고유 사본으로 다시 직접 확인했다. 태블릿과 신발 사이에 빈 간격이 생겼고 인물 포즈는 유지됐다.

현재 A에서 요청했던 실제 접촉/겹침 수정은 확인 완료다. 추가 디자인 수정 요청은 없다. 이는 품질에 대한 사용자 최종 승인이나 실시간 영상의 모든 순간을 검증했다는 뜻은 아니다.
