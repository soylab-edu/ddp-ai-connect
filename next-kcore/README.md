# NEXT K-CORE AI CONNECT

01번 레퍼런스의 큰 키네틱 타이포 표지를 참고한 행사 참여 제안서입니다. 헤더에 24초 Hyperframes 모션을 넣었으며 직선→곡선→원형으로 변하는 선 위를 사람과 AI가 앞으로 걷습니다.

- 실행: `D:\DDP\03_NEXT_KCORE_AI_CONNECT.html`을 브라우저에서 엽니다. 이미지·CSS·JS가 포함된 단일 파일입니다.
- 편집: `index.html` (본문), `styles.css` (스타일), `content.js` (강의·기업·공간 내용), `app.js` (동작).
- 재생성: 헤더 수정 시 `python hero-motion/compile.py` 실행 후 `python build.py` 실행.
- 헤더 편집: `hero-motion/layout.template` (화면 구성), `hero-motion/motion.js` (24초 타임라인·보행). `hero-motion/index.html`은 컴파일 결과입니다.
- 헤더 검증: `npm run check --prefix hero-motion`. 정적 구성·실행·레이아웃·모션 오류 0, 글자 대비 검사 38/38 통과. 장면 전환 중 의도적인 겹침 경고는 남아 있습니다.
- 개발 미리보기: `python -m http.server 8765 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8765/`.
- Google Fonts는 온라인에서 로드되며 연결이 없으면 시스템 한글 글꼴로 표시됩니다.

## 신청 폼 연결

`content.js`의 `EVENT.registrationUrl`에 실제 폼 URL을 넣습니다. 세션마다 다른 신청 페이지를 사용할 경우 각 `sessions` 항목의 `formUrl`을 입력합니다. 비어 있으면 신청 일정 추후 공개 안내 창이 표시되며 개인정보를 수집하지 않습니다.

## 디자인 자료

원본 이미지는 변경하지 않고 assets에 복사해 사용합니다. 투명 PNG 10종은 헤더에서 등장·확대·회전·교체됩니다. 인터랙션1의 사람·AI 모티브는 관절을 가진 SVG 캐릭터로 재구성했습니다. 발을 딛는 구간에는 발의 경로 좌표를 고정하고, 반대 발은 들어 앞으로 옮기는 보행입니다. 직선에서는 왼쪽→오른쪽, 원에서는 둘레를 따라 전진합니다. 중간 본문의 타이포 실험 영역은 제거했습니다. GSAP, 헤더 폰트, 이미지가 배포 HTML 안에 포함됩니다.

`hero-motion/snapshots/contact-sheet.jpg`에서 6개 시점의 실제 화면을 확인할 수 있습니다. 인터랙션2는 두 로고가 검은 배경에 합쳐져 있고 빨간 표시가 남아 있어 공식 로고로 재사용하지 않았습니다. 주최·주관·운영은 요청한 정확한 텍스트로 표시했습니다.

## 부제 후보

1. AI로 이어진 사람들 — 사람과 교류를 강조하는 현재 시안.
2. AI를 사이에 두고, 사람이 만나다 — 기존 기획의 메시지가 가장 잘 드러나는 표현.
3. 창작으로 만나, 다음으로 연결되다 — 교육 성과에서 기업·사회로 이어지는 의미.
