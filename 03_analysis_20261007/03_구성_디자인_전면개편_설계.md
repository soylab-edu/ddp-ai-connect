## 1. 결론

03번은 이미 01번과 같은 폰트 계열, 최대 1160px 본문, 큰 챕터 번호, 밝은 배경과 카드 구조를 사용한다. 따라서 폰트나 색을 조금 바꾸는 것으로는 01번의 정돈된 인상을 얻기 어렵다. **헤더의 시각적 중심을 하나로 만들고, 행사 정보의 우선순위를 다시 정하며, 본문에서 반복되는 장식을 줄여야 한다.**

권장 방향은 **“AI를 사이에 두고, 사람과 사람이 만나는 자리. SOYLAB은 사람들을 모으고 그들과 함께한다”**이다. 게임·예술·이야기는 서로 만나게 하는 계기다. 기존 걷는 인물, 경로 선택, 반복 SOYLAB 문자 이미지, 액체 로고, 여섯 장면의 쇼릴을 전면 교체한다. 새로운 모션은 서로 다른 창작을 통해 사람들이 모이고 연결되는 과정을 보여준다. 행사명·일정·장소·행사 내용은 모션 시작 전부터 읽혀야 한다.

최종 메시지 위계는 **사람과 사람의 만남 → AI와 창작이라는 매개 → 함께할 자리를 만드는 SOYLAB**이다. SOYLAB이 연결의 구심점이 된다는 뜻은 사람들이 모이고 대화하고 함께할 수 있는 자리를 만든다는 뜻으로 표현한다. 헤더에서 사람을 가장 크게, AI를 사람 사이의 작은 연결 요소로, SOYLAB을 그 자리를 만드는 브랜드로 보여준다. 브랜드 지향점을 표현하는 설계이며 기존 주최·주관·공동 운영 기관의 공식 역할은 유지한다.

이 문서는 설계안이다. 원본 HTML은 수정하지 않았다. 판단 근거는 두 HTML의 소스와 03번에서 추출한 원본 이미지이며, 실제 브라우저의 화면·프레임률·반응형 동작은 검증하지 못했다. 미적 판단 중 화면에서 확인이 필요한 것은 제안으로 구분했다.

## 3. 왜 현재 화면의 세련된 인상이 약해지는가

| 현재 소스에서 확인한 요소 | 인상·전달상 문제에 대한 판단 | 수정 방향 |
|---|---|---|
| 큰 AI間, 한글 제목, 배경 글자, 인물 행렬, HUD, 카운트다운, 쇼릴이 같은 헤더 안에 있음 | 어디를 먼저 볼지 결정하기 어려운 구성 | 주인공을 하나의 타이포그래피와 연결 모션으로 제한 |
| 텍스트 자체를 작은 `soylab.ai` 반복으로 채운 래스터 그래픽 | 작은 화면에서 세부 무늬가 문자보다 먼저 보일 수 있음 | 매끈한 HTML 타이포그래피와 단순한 면·선으로 교체 |
| 보라·검정·형광 라임을 오가는 장면과 다색 액체 파티클 | 장면마다 다른 행사처럼 느껴질 위험 | 보라·중성색 중심, 라임은 작은 강조에만 사용 |
| 행사 소개보다 THE CLASS 모집 성과와 독립적인 운영사 로고 쇼가 쇼릴 앞부분에 등장 | 방문 목적과 SOYLAB의 역할이 연결되지 않음 | 교육 성과는 본문의 배경 정보로, SOYLAB은 연결을 만드는 주체로 헤더와 모션에 통합 |
| 장면별 단어 교체 520/610ms, 걷기·경로 변경·카운트업·재생 타이머가 별도로 동작 | 서로 다른 리듬이 중첩됨 | 하나의 시간축과 공통 가감속으로 통합 |
| 6장면 × 2.9초 + 0.3초 = 17.7초 후 표지, 9초 뒤 자동 재시작 | 읽는 중 화면이 다시 바뀜. SKIP도 9초 뒤 재시작됨 | 장면별 강약을 설계한 짧은 쇼릴 후 정지, 명시적 다시 보기 |
| 첫 진입에서 기업·관람·강의의 동선 선택부터 제시 | 행사 이해 전에 선택을 요구함 | 먼저 통합 행사 설명, 그 뒤 목적별 참여 안내 |
| ‘네 가지 주제’에 사람–AI–사람과 세 장르를 같은 층위로 배치 | 행사 철학과 장르가 서로 같은 분류처럼 보임 | 공통 원리 1개 + 창작 장르 3개로 위계 정리 |

01번에서 가져올 것은 **큰 것과 작은 것의 대비, 장면별 단일 초점, 숫자→분류→제목→설명의 순서, 공통 여백과 카드 규칙**이다. 01번의 빨강, 모든 장면 효과, 긴 CTA 지연을 그대로 복제할 필요는 없다.

주요 버튼은 **‘프로그램 보기’**, 보조 버튼은 **‘참여 방법’**으로 권장한다. 신청 링크가 비어 있는 현재는 ‘신청하기’를 첫 화면의 유일한 주 행동으로 사용하지 않는다. 실제 링크가 입력되면 해당 강의 카드에서 ‘강의 신청’을 활성화한다. SOYLAB 브랜드는 첫 화면에서 선명하게 보이게 하되, 외부 사이트로 나가는 버튼은 행사 참여보다 낮은 위계의 보조 링크로 둔다.

기존 ‘AI를 사이에 두고, 사람이 만나다’의 사람 중심 철학을 이어받되, 화면의 위계와 모션을 그 메시지에 맞게 다시 만든다. 주 제목에서 만남의 의미를 선언하고, 바로 다음 문장에서 행사 종류·장르를 구체적으로 설명한다. 브랜드 슬로건만 보고 무슨 행사인지 추측하게 하지 않는다.

## 5. 헤더 구성

### 권장안: 헤더 전체가 움직이는 행사 포스터

1. 표지 상단의 작은 고정 식별 영역: NEXT K-CORE AI CONNECT / SOYLAB / 2026.
2. 헤더의 넓은 중앙 전체를 모션 무대로 사용한다. 글자·형태가 화면을 점유하고, 장면마다 하나의 메시지를 전달한다.
3. 표지 하단의 고정 정보 영역: 날짜·장소·게임·예술·이야기의 통합 행사라는 설명·프로그램 보기. 애니메이션 장면과 독립적으로 읽힌다.
4. 쇼릴의 최종 정지 화면에 ‘AI를 사이에 두고, 사람과 사람이 만나다’가 완성된다. 같은 표지 안에서 독자가 정보를 읽고 다음 내용으로 이동한다.
5. 본문부터 01번과 같은 최대 1160px의 차분한 편집형 레이아웃으로 전환한다.

전면 모션 무대 안에 또 하나의 작은 카드·도표 박스를 만들지 않는다. 큰 ‘사람’ 글자, 사람 사이에 생기는 공간, 그 공간을 통과하는 AI와 창작 장르가 모션의 재료다. 타이포의 크기 변화·면 분할·마스크·형태 변환·장면 연결로 밀도와 여백을 조절한다.

모바일에서는 같은 장면을 단순 축소하지 않고 세로 구도에 맞춰 글자의 이동과 줄바꿈을 다시 설계한다. 날짜·장소·참여 경로는 모션에 덮이지 않도록 하단 정보 영역의 공간을 확보한다. 표지는 01번처럼 넓게 사용하되, 낮은 화면에서는 내용 높이에 따라 늘어나도록 한다.

색과 테마는 레퍼런스에 맞춰 명시적으로 정한다. 앱의 다크 모드를 따라 제안 화면이 임의로 어두워지지 않게 한다. 보라색 유지 여부와 별개로, 01번의 큰 대비·단색 면·정돈된 여백을 재현하는 것이 기준이다.

`間`은 필수로 유지할 전제가 아니다. 사람과 사람의 만남, 그 사이의 AI, 만남을 만드는 SOYLAB의 역할이 중심이다. 유지한다면 하단 크레딧이나 섹션 구분에만 작게 사용한다.

## 6. 모션 설계 — ‘사람 사이’를 따라가는 전면 쇼릴

아래는 14초를 시작점으로 한 장면 설계다. 실제 연출과 가독성을 확인한 뒤 컷 길이를 조정한다. Student Kit의 ‘하나의 모티프가 장면을 거쳐 변한다’는 구조와 Skill Pack의 타이포·행사 프로모션 연출을 참고한다.

| 시간 | 화면과 동작 | 전달 의미 |
|---|---|---|
| 0.0–1.8초 | 화면을 크게 점유하는 ‘사람’ 한 단어. 작은 시작 형태가 글자의 일부로 확장됨 | 이야기의 출발점은 사람 |
| 1.8–4.0초 | ‘사람’이 양쪽으로 나뉘며 사이가 열림. 그 사이에 작은 AI가 나타남 | 사람과 사람 사이의 AI |
| 4.0–6.5초 | 열린 공간이 화면 전체로 확장되며 게임·예술·이야기 타이포와 형태가 차례로 전환됨 | 서로 다른 창작을 만나게 하는 계기 |
| 6.5–9.0초 | 여러 형태가 같은 리듬으로 모이고 연결됨. ‘함께 보고 / 배우고 / 이야기하다’가 컷에 맞춰 등장 | 함께하는 행사 경험 |
| 9.0–11.5초 | 형태가 열리며 ‘AI를 사이에 두고, 사람과 사람이 만나다’가 하나의 완성된 포스터로 정리됨. SOYLAB 크레딧 결합 | 사람들의 만남을 만드는 브랜드 |
| 11.5–14.0초 | 최종 포스터를 충분히 보여주고 정지 | 행사 정보 읽기와 참여로 전환 |

행사명·날짜·장소·행사 성격·버튼은 위 시간축의 영향을 받지 않고 계속 보인다. 메인 한글 카피는 모션층의 큰 주인공으로 사용하며 작은 고정 제목과 중복 경쟁시키지 않는다. 어떤 장면에서 멈춰도 “언제, 어디서, 무엇을 하는 행사인지” 파악할 수 있어야 한다.

**동작 규칙:** 한 컷의 주인공을 하나로 정하고, 나가는 형태의 방향·크기·속도를 다음 형태의 등장으로 연결한다. 큰 타이포와 형태 변환에 충분한 화면 면적을 주며, 강한 컷 뒤에는 읽는 구간을 둔다. 여러 효과를 동시에 중첩하기보다 장면별 역할을 나눈다. 이 시간축은 설계값이며 실제 렌더링 후 조정한다.

**상태 규칙:** 1회 자동 재생→정지. 다시 보기는 사용자가 요청했을 때만. 중간 정지와 건너뛰기를 제공하고, 건너뛰면 재시작 타이머를 남기지 않는다. 모션 감소 설정에서는 최종 정지 화면을 즉시 표시한다. 화면 밖·백그라운드에서는 재생을 멈춘다. 장식용 모션은 접근성 트리에서 제외하고 핵심 정보는 실제 텍스트로 제공한다.

## 7. 페이지 흐름도 함께 바꾸기

| 새 순서 | 섹션 | 독자가 얻는 답 | 현재 내용의 처리 |
|---|---|---|---|
| 첫 화면 | 행사 선언 | 언제·어디서·무엇을·왜 | 헤더 전면 교체 |
| 01 | 세 장르, 하나의 행사 | 게임·예술·이야기가 어떻게 연결되나 | 소개·네 가지 주제·목표를 재편 |
| 02 | 이틀의 프로그램 | 어떤 날 무엇을 볼 수 있나 | 날짜 탭·타임라인 유지, 공개 대상 표시 강화 |
| 03 | 전시·상영 | 어떤 창작 결과물을 만나나 | 기존 작품 필터·모달 유지 |
| 04 | 함께 배우고 교류하기 | 강의와 기업 참여는 무엇을 더하나 | 무료강의와 기업 참여의 관계를 먼저 요약 |
| 05 | 기업 참여 제안 | 참여하면 어떤 활동을 할 수 있나 | 상세 시나리오·표 유지, 후보 상태 명시 |
| 06 | 공간 안내 | 한 공간에서 무엇이 이어지나 | 공간 갤러리·개념 배치도 유지 |
| 07 | 나에게 맞는 참여 방법 | 어떻게 참여하고 찾아가나 | 기존 목적별 동선·FAQ·교통·캘린더 연결 |

기업 제안 독자가 중요하므로 상단 메뉴에 ‘기업 참여’를 바로 갈 수 있게 둔다. 하지만 일반 방문자가 보는 첫 본문에서 회사별 가상 시나리오를 작품보다 먼저 길게 읽게 하지는 않는다. 기존 `#partners`, `#works`, `#lectures` 등의 앵커 ID는 유지할 수 있고, 번호·내비게이션·추천 동선 목록은 새 순서와 함께 갱신한다.

### ‘통합’이 내용으로 보이게 하는 방법

세 장르 카드를 같은 크기·같은 위계로 배치하고, 아래에 공통 활동인 **보기(전시·상영) → 배우기(강의) → 연결하기(교류)**를 가로로 잇는다. 이 흐름의 연결 주체를 SOYLAB으로 명시한다. 원본에 없는 장르별 독립 강의나 확정 기업 협업은 만들지 않는다. 작품 정보가 비어 있어도 ‘장르 3개를 한자리에서 경험하고 서로 연결된다’는 구조는 먼저 보여줄 수 있다.

### SOYLAB의 구심점 역할을 본문에서 증명하기

- **모으기:** 게임·예술·이야기 작품을 같은 무대에 엮는 행사 구성.
- **만나게 하기:** 전시·상영·강의·시연·교류가 서로 단절되지 않는 프로그램과 공간 동선.
- **이어가기:** 기업 참여 안내와 협업·교육 상담으로 다음 대화를 시작할 수 있는 경로. 행사 뒤 커뮤니티나 매칭 서비스를 제공한다고는 확정 없이 약속하지 않는다.

브랜드 위계는 **사람과 사람 = 행사의 중심 / AI·창작 = 만남의 매개 / SOYLAB = 함께할 자리를 만드는 주체 / NEXT K-CORE AI CONNECT = 행사명 / 게임·예술·이야기 = 창작 장르 / 전시·상영·강의·교류 = 만나는 방식**으로 구분한다. 공식 주최·주관·공동 운영 표기는 원본 그대로 하단에 명확히 둔다.

THE CLASS 지원자 764명·경쟁률·12주 과정은 행사의 배경을 증명하는 정보다. 첫 화면에서 내려 소개 하단의 작은 ‘창작의 배경’ 블록으로 정리한다. 움직이는 764개 점과 계속 바뀌는 색상은 정적인 수치와 간결한 도표로 대체한다.

현재 ‘부제 후보 5’는 디자인 검토 기능이다. 공개 행사 페이지에는 선택된 한 문장만 보여주고, 후보 선택은 별도 검토 영역으로 옮긴다. 원본이 참여 제안서이므로 기업 후보·가상 이미지의 상태 표시는 계속 유지한다.
