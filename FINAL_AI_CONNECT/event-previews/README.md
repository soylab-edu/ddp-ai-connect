# 행사 활동 예상도 6종

행사내부 폴더의 배경 사진과 기존 공간 시안을 참조해 built-in image_gen으로 생성한 가로형 이미지입니다. index.html에서 6종을 확인할 수 있습니다. 각 PNG 옆 TXT 파일에 생성 프롬프트를 보관했습니다.

01 리플렛 관람 / 02 빠나나AI 가입 / 03 무료강연 실습 / 04 노트북 학습 / 05 게임 설치·플레이 / 06 취업·교육 상담.

실제 행사 현장 사진이 아닌 예상도이며 프로그램 운영·기업 참여 확정을 뜻하지 않습니다. 게임 체험은 이번 요청으로 만든 시각 제안이며 기존 웹페이지의 운영 내용을 확정 변경한 것은 아닙니다. 해당 이미지는 예시이며, 실제로 부스 제작에 사용되는 비용은 제공되지 않습니다.

메인 웹페이지의 사진을 자동 교체하지 않고 별도의 이미지 검토 페이지로 보관합니다.

브랜드 정정: 02는 국내 플랫폼 빠나나AI(BBANANA) 가입 안내 예상도다. 기존 기업 조사와 노란 BBANANA 부스 시안을 참조해 표지판과 화면 브랜드를 수정했다. 화면 UI는 예상도용 구성이다. 이전 nano-banana 파일은 폐기 시안으로 사용하지 않는다.
